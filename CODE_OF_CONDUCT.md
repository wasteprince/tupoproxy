# Code of Conduct

tupoproxy is a technical project. Contributors are expected to keep discussion
respectful, specific, and useful to the work.

## Expected behavior

- Critique code and ideas, not people.
- Assume good faith while still asking for evidence.
- Protect secrets, personal data, and operational details shared in reports.
- Respect maintainers' time by providing reproducible information.
- Accept correction and make room for contributors with different experience.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate disruption, publishing
private information, or using project spaces to coordinate harm are not
accepted.

## Enforcement

Maintainers may edit or remove content, close discussions, reject changes, or
temporarily or permanently restrict participation when necessary to keep the
project safe and workable. Serious safety concerns should be reported privately
to the repository owner rather than posted with exploitable operational detail.
